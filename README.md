# 🍽️ Zomato Bangalore Power BI Dashboard

## 📌 Project Overview
This project presents an interactive Power BI dashboard that analyzes Bangalore's Zomato restaurant dataset. It provides insights into restaurant performance, customer ratings, reviews, cuisines, pricing, and takeaway/delivery services, enabling users to make data-driven decisions.

---

## 🎯 Problem Statement
The restaurant industry in Bangalore is highly competitive, with thousands of restaurants offering different cuisines, pricing, and delivery services. Customers often struggle to identify the best restaurants based on ratings, reviews, and cost. Restaurant owners also require insights into customer preferences and market trends to improve business performance.

This dashboard analyzes restaurant data to uncover meaningful insights into ratings, reviews, pricing, cuisines, and service availability.

---

## 📊 Dashboard Features
- Total Restaurants
- Average Dining Rating
- Average Delivery Rating
- Total Reviews
- Average Cost
- Rating Gap Analysis
- Restaurant Distribution by Area
- Cuisine Analysis
- Top Restaurants by Reviews
- Review Distribution
- Deep Analysis Dashboard
